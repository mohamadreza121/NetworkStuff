# Design system

NetPath's interface is overwhelmingly neutral: obsidian backgrounds, graphite surfaces,
platinum typography, thin borders, restrained corners, and compact technical metadata.

- Blue and cyan indicate selected or active technical state.
- Green, amber, and red indicate healthy, warning, and critical state.
- Violet is reserved for automation context.
- Color is never the only status signal.
- Primary actions use platinum surfaces with dark text.
- Ordinary panels use 4–10px corners; structural sections rely on borders and grids.
- Motion communicates navigation or traffic and honors `prefers-reduced-motion`.
- Use pills only when their closed shape materially improves scanning.

Reuse existing buttons, terminals, topology panels, filters, tables, search primitives,
and content shells before introducing another component pattern.
