# Projects and downloads

Project pages are engineering case studies. They should demonstrate design intent,
address planning, routing, switching, security, services, automation, validation,
troubleshooting, and documentation.

## Practice version

May contain topology, device placement, addressing, requirements, worksheets, and a
minimal configuration scaffold. It must not expose the completed answer unintentionally.

## Completed version

May contain original configuration text, verification captures, documentation, and
troubleshooting notes that the repository owner is allowed to redistribute.

## Licensing boundary

Never commit Cisco IOS, IOSv, IOS-XE, qcow2 appliance images, FortiGate/Palo Alto VM
images, Windows/Linux ISOs, GNS3 VM disks, or any other proprietary appliance image.
Project pages should explain how a learner can supply legally obtained images without
bundling them.
