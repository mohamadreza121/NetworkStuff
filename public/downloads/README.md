# Download assets

NetPath keeps only small, editable, legally distributable learning assets here.

- `worksheets/` contains reusable evidence and troubleshooting templates.
- `labs/` contains starter and solution manifests, not proprietary project files.
- `ansible/` contains editable automation examples.

Do not commit vendor appliance images, VM disks, ISO files, licensed course
material, private configurations, credentials, packet captures with sensitive
traffic, or large videos. Host approved large media externally and link to it
from structured lesson content.
